## Research Limitations & Next Steps

### OpenArchieven API Limitations Encountered:
1. Many records return HTTP 404 when fetching metadata
2. Searches by name return alphabetically sorted results, not by date/relevance
3. Combined name searches (e.g., "Cornelissen Verhoeven") return 0 results
4. BHIC-specific archive_id filtering still returns global results

### Recommended Next Steps:

1. **BHIC Direct Search** — Access https://www.bhic.nl directly with:
   - Bakel en Milheeze civil registry (BS) 1870-1880
   - Population registers (Bevolkingsregister) 1860-1890

2. **WieWasWie.nl** — Alternative genealogy portal with different indexing

3. **DTB Records** — Church records (Doop/Trouw/Begraaf) for pre-1811 ancestors:
   - Bakel parish records
   - Milheeze parish records

4. **Marriage Records Priority** — Marriage certificates typically list:
   - Full names of both spouses
   - Ages and birthplaces
   - Names of parents (often 4 parents listed)
   - Witnesses (often relatives)

5. **Death Records** — Later death records (1900-1950) of Martinus Verbruggen and Peter Cornelissen would show:
   - Birth date and place
   - Parents' names
   - Spouse's name
