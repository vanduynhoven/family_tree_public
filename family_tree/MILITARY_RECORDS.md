## What Dutch militia registers contain

Each `Militieregister` (national-militia conscription register, men at ~19–20) typically records:
- **Full name** and **exact birth date + birth place**
- **Parents' names** and **residence** (on the scanned page)
- **Physical description** — height, face, hair/eyebrow/eye colour, nose, mouth, chin, distinguishing marks (on the scanned page)
- **Militia outcome** — enrolled, exempted, substitute, drawn lot number

The Open Archieven **index** exposes name + birth date/place + conscription year/place. The **physical description and parents** live on the **scanned register page** (linked per record — image URLs included below).

## Reproduce / extend these searches

Dutch militia registers (free public JSON API, no login):
```bash
# All Van Duijnhoven militia records (paginate start=0,100,200 — 266 total)
curl -s "https://api.openarchieven.nl/1.0/records/search.json?name=van%20Duijnhoven&sourcetype=Militieregisters&number_show=100&start=0"

# Full detail for one record (birth date/place, source, scan images):
curl -s "https://api.openarchieven.nl/1.0/records/show.json?archive=bhi&identifier=<IDENTIFIER>"
```
- Note: the sourcetype is **`Militieregisters`** (plural). `Militieregister` (singular) returns 0.
- Detail records return **scan image URLs** (`images.memorix.nl/bhic/...`) and a **BHIC deed link** (`bhic.nl/memorix/genealogy/...`) where the physical description and parents are visible.

US records — no free API; use FamilySearch (login), NARA St. Louis (SF-180), Fold3/Ancestry (subscription).
